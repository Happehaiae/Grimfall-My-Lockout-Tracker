# My Lockouts Tracker (Mythic 0)
A lightweight World of Warcraft 3.3.5a addon that tracks Mythic 0 dungeon lockouts across expansions, synchronizes data with your party/raid group, and features a clean visual UI and minimap button.

## Features
* **Visual UI Window:** Draggable, scrollable panel organized by expansion.
* **Group Synchronization:** Automatically cross-references lockouts with group members running the addon and flags non-users as "Unknown".
* **Minimap Integration:** Quick toggle button with tooltips.
* **Chat Broadcasting:** Post verified available Mythics straight to Party or Raid chat.
